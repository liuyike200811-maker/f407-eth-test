# 传感器实时跟随功能 —— 协议与操作（合并自3份重复文档 + 111报告，2026-07-19状态）

数据链路总览：
```
WT901传感器 --WiFi/UDP--> Windows电脑 --USB转TTL--> 板子 USART6(PC7)
                                                      板子解析→踝角→驱动3电缸跟随
触发: HMI Modbus 线圈 0x0009 (或板子串口命令 s)
退出: HMI 急停 0x0006 (或板子串口命令 x)
```
板子端（STM32F407）已全部完成并编译验证通过（0告警）。

## 一、物理链路（必须一致）

| 项目 | 约定值 |
|---|---|
| 板端接收口 | **USART6_RX = PC7**（USB转TTL的TX→PC7，GND对GND；板子只收不发，PC6/RX不用接） |
| 电平 | **3.3V TTL**（⚠绝不能用5V/RS232直连，会烧PC7） |
| 波特率 | 115200，8N1 |

## 二、传感器帧格式（Windows端往串口写什么）

**原样透传 WiFi/UDP 抓到的 54 字节帧，不要拆包重组**：
```
[12B 设备ID ASCII，以"WT"开头] + [40B 载荷] + [0x0D 0x0A]  = 共54字节
```
板端只解析载荷里这几处：

| 载荷偏移 | 内容 | 解算 |
|---|---|---|
| 22-23 | Roll (int16小端) | ×180/32768=度 → 映射α(内翻外翻) |
| 24-25 | Pitch (int16小端) | ×180/32768=度 → 映射β(跖屈背伸) |
| 38-39 | 固件版本号(uint16小端) | 必须==**13032**，防错位校验 |

- 板端靠**串口空闲(IDLE)判帧尾**，每帧留≥1字符间隙；传感器本身~20Hz(~50ms/帧)天然满足
- 板端自带校验：帧长≠54 / 不以"WT"开头 / 帧尾≠0D0A / 版本≠13032 → 整帧丢弃，不会驱动电缸乱动
- 测试自检：看板子串口打印"标定收到N帧"即知格式对不对

## 三、HMI(FStudio) 加按钮

通讯参数不变（Modbus RTU, 115200, 8, N, 1, 从站号1），和现有5个模式按钮同款配法：

| 功能 | 类型 | 线圈地址(原始/1基) | 动作 |
|---|---|---|---|
| 传感器跟随 | 位按钮·点动(瞬动)型 | **9 / 0x00010** | 按下写ON，板子执行后自动清0 |
| 退出（复用急停，不用新加） | — | 6 / 0x00007 | 跟随中按下→板子自动归平→下降→回待机 |

规律：故障复位是8/0x00009，往下顺延一个就是传感器跟随按钮；地址填"原始"还是"1基"看你FStudio工程习惯，对不上就在两者间换着试。

（可选）状态指示：反馈区"当前模式"(保持寄存器4x0024)传感器跟随时值=6，可加判断显示"传感器跟随中"。

参数提醒：跟随模式**只用到**设定区的"升高(mm)、升速(RPM)"，α/β/频率/波幅/循环次数在此模式下不生效，进跟随前确认"升高"设了合理值。

## 四、坐标系对齐（治疗师手持演示时必须现场对齐）

平台世界坐标（俯视）：
```
                +Y (90°)
                 │
   2号(120°) ●   │            +X  精确指向 1号电缸
              ╲  │            +Y  在 2号那一侧(最近2号，不精确对准任一缸)
               ╲ │            -Y  在 3号那一侧
    ────────────●────────────►  +X (0°)
               ╱ │          ● 1号
              ╱  │            α(内翻/外翻) = 绕X轴 = Roll
   3号(240°) ●   │            β(跖屈/背伸) = 绕Y轴 = Pitch
                 │            Z竖直向上
                -Y (270°)
```
- 对齐只需管X：右手系，把传感器**+X（贴个箭头）对准1号电缸方向**，Y/Z自动就位
- 标定：治疗师手持，标定那~1秒把传感器**水平放置+箭头朝1号缸保持不动**，板子记为零点
- 方向若反了（脚往左倾、平台往右动）：改 `ecat_motion.c` 的 `run_sensor_mode()` 里 `ar`/`br` 计算加个负号（一行）

## 五、操作流程（上电到跟随，完整顺序）

```
1. 上电 → 先按【归零】              ← 每次开机必须，否则超程报警
2. 待机 → 按【传感器跟随】(线圈0x0009，仅待机受理)
3. 板子自动：上升到工作高度 → 提示"零偏标定"
4. 标定的~1秒：传感器水平放、箭头朝1号缸、保持不动   ← 关键，决定零点
5. 标定完 → 实时跟随：传感器怎么倾，平台跟着倾
6. 结束 → 按【急停】(0x0006)：板子自动 归平→下降→回待机
```

## 六、板子端自动安全兜底（不用管，板子自己处理）

- 标定期几乎收不到帧(<5帧) → 判链路没通，打印提示并自动退出，不乱动
- 跟随中信号丢失>300ms → **冻结保持**当前姿态，信号恢复自动继续
- 从站驱动器报警 → 就地降速回待机
- 角度限幅±20°(`SENSOR_MAX_DEG`)、死区0.3°、EMA平滑α=0.2 —— 都在`ecat_motion.c`顶部可调宏

| 现象 | 怎么调 | 位置 |

## 关键结论（版本冲突已裁定）

1. **寄存器契约以 v4（2026-07-21）为准**：反馈区地址是 **4x0016~4x0024**，不是旧文档里写的 4x0010~4x0018——这是文档笔误，代码从未变过，v4 只是改正了文档。
2. **数字孪生帧以 32 字节版（含 `0xAA55` 帧头 + 1 字节 `xor` 校验）为准**，`数字孪生对接-补充说明.md` 里描述的"31字节无校验"版本是早期不完整的描述，已废弃。
3. **传感器跟随功能**：线圈 `0x0009` 触发（仅待机受理，归零优先），复用急停 `0x0006` 退出，反馈"当前模式"=6 时表示跟随中，均已定稿，`.claude` 中的三份重复文档内容一致，无冲突。
